# 물체감지 타이밍. 물체감지 타이밍

**목적** — gPO 정지 → gOBJ=2 전환 지연(디바운스) 측정
**수행** — 2026-07-22, 시편 A 파지, rFR 4단계 × rSP 4단계 = 16조합 × 2회 = 32회

## 디바운스란

신호가 잠깐 튀는 것을 진짜 변화로 착각하지 않도록, **일정 시간 조건이 유지될 때만 상태 전환을 인정**하는 처리다.
기계식 스위치 접점이 붙었다 떨어지며 여러 번 튀는 현상(bouncing)을 걸러내는 데서 나온 말이다.

여기서는 **손가락이 물체에 닿아 멈춘 뒤, 펌웨어가 곧바로 gOBJ=2(파지)로 바꾸지 않고 잠시 확인한 뒤 전환하는 지연**을 가리킨다.
이 대기가 있어야 순간적인 걸림이나 진동을 파지로 오판하지 않는다.

**측정 정의** — gPO 값이 더 이상 변하지 않은 시점부터 gOBJ가 0이 아닌 값으로 바뀐 시점까지의 시간.
`run.py` 의 `_timed_grasp()` 가 두 레지스터를 2 ms 주기로 함께 읽어 계산한다.

> **주의** — 이 값에는 펌웨어의 판정 지연 외에 **gPO 레지스터 갱신 지연**도 섞여 있다.
> 속도 스텝응답 분석에서 확인했듯 gPO는 전행정 중 3~7회만 갱신되므로, '더 이상 변하지 않은 시점'이 실제 정지보다 이를 수 있다.
> 따라서 239 ms는 펌웨어 순수 디바운스의 **상한에 가까운 값**으로 읽어야 한다.

## 결과

| 항목 | 값 |
|---|---|
| gOBJ=2(파지) 성립률 | **32 / 32 = 100%** |
| 디바운스 | **238.8 ± 2.5 ms** (n=15, 231.8 ~ 243.0) |
| 정지 gPO | 35 ~ 37 |
| 환산 개구 | 45.6 mm |
| 시편 직경 | Ø45 mm (차이 0.6 mm) |
| 파지력 최대 | 209.9 N (로드셀 2채널 합) |

rSP별 디바운스: 128 → 238.6 ± 3.1 ms (n=8) · 192 → 238.6 ± 1.2 ms (n=6) · 255 → 241.0 ms (n=1)

## 해석

**디바운스는 약 239 ms의 상수이고 rSP·rFR에 의존하지 않는다.** 산포가 ±2.5 ms에 불과해,
시뮬의 파지 판정 지연은 조건별 함수가 아니라 고정 지연 하나로 모델링하면 된다.

정지 gPO 35~37을 버니어 보정 보정식으로 환산하면 45.6 mm로 시편 실측 Ø45 mm와 0.6 mm 차이다.
**버니어 보정 보정식이 파지 상태에서도 유효함을 시편 직경으로 재확인**한 셈이다.

rSP=32(저속) 조합 8회에서는 디바운스가 기록되지 않았다. 이동이 느려 gPO 정지 판정보다 gOBJ 전환이 먼저 일어났기 때문이며,
결측이 아니라 저속 구간의 정상 거동이다.
