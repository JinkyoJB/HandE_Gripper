# 버니어 보정

**목적** — count ↔ mm 보정 커브 도출
**수행** — 2026-07-15, rPR 7단계(32·64·96·128·160·192·224) × 닫힘/열림 2방향, 지점당 3회 읽기

## 결과

| 항목 | 값 |
|---|---|
| **보정식** | **개구[mm] = 53.489 − 0.21644 × gPO** |
| 결정계수 | R² = 0.999984 |
| 잔차 | RMS 0.055 mm · 최대 0.093 mm |
| 1 count 당 개구 | 0.2164 mm (사양 ≈ 0.2 mm) |
| 히스테리시스 | 평균 0.081 mm · 최대 0.17 mm (rPR=192) |
| gPO ↔ rPR | 14지점 전부 **gPO = rPR** (오차 0 count) |
| 환산 전행정 | 53.24 mm (gPO 3 → 249) |

## 해석

매뉴얼의 "준선형(quasi-linear)" 표현은 실측상 **사실상 선형**이다. 14점 회귀의 R²가 0.99998이고 잔차 최대가 0.093 mm이므로,
count↔mm 변환에 1차식이면 충분하다.

방향별 차이(히스테리시스)는 평균 0.081 mm로, 공칭 반복정밀도 0.025 mm보다는 크지만 합격 기준 0.5 mm에 비하면 작다.
부호가 일정하지 않은 것(rPR 64·224에서 음수)으로 보아 계통적 백래시라기보다 측정 산포에 가깝다.

미학습 조합 검증에서 이 보정식을 레이저 실측과 대조한 결과 RMSE 0.309 mm로, 보정식 자체의 잔차(0.055 mm)보다 크다.
차이는 1차식이 잡아내지 못한 미세 비선형에서 온다.
