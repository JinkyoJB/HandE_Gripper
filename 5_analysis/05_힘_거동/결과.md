# 힘 거동

**목적** — rFR·rSP ↔ 파지력 관계 확인, gCU 로 파지력을 추정할 수 있는지 판단
**수행** — 2026-07-22, 시편 A(Ø45 mm) 파지 상태(gOBJ=2)에서 rFR 4단계 × rSP 4단계 × 2회 = 32회

> **파지력 산정 규약** — 시편은 원통을 2분할해 로드셀 2EA 를 축방향에 매설한 구조다
> (장비 매뉴얼 Fig. 3-2-5). 두 채널이 하나의 조임 하중을 나눠 받으므로 **합**이 파지력이다.
> KS B ISO 18646-3 5.3.3 — *"잡기 힘은 로드 셀의 두 평균값의 합으로 결정된다."*

## 결과

**rSP = 128 고정**

| rFR | 파지력 [N] (n=2) | gPO 정지 | 정지 개구 [mm] | 사양식 [N] |
|---|---|---|---|---|
| 0 | 미측정 | — | — | 20 |
| 64 | 106.5 ± 0.9 | 36 | 45.70 | 61 |
| 128 | 130.8 ± 0.3 | 36 | 45.59 | 103 |
| 192 | 149.3 ± 0.05 | 37 | 45.54 | 144 |
| 255 | 161.6 ± 0.5 | 37 | 45.54 | 185 |

정지 개구가 시편 실측 Ø45 mm 와 0.5~0.7 mm 차이로 맞는다. 조합 내 2회 반복 편차는 평균
0.7%, 최대 4.4% 다.

**rFR × rSP 전체** (16조합, N)

| rFR \ rSP | 32 | 128 | 192 | 255 |
|---|---|---|---|---|
| 64 | 83.6 | 106.5 | 136.1 | 163.7 |
| 128 | 103.9 | 130.8 | 155.4 | 178.4 |
| 192 | 121.0 | 149.3 | 167.8 | 188.8 |
| 255 | 141.0 | 161.6 | 178.2 | 197.2 |

**F [N] = 61.2 + 0.2446 × rFR + 0.3126 × rSP** (R² = 0.977, n = 32)

## 곡선이 사양식보다 완만하다

실측 최대는 197 N 으로 사양 최대 185 N 을 넘어선다. 크기가 모자란 것이 아니라 기울기가 다르다.

| | 기울기 [N/count] | rFR=0 외삽 | rFR=255 |
|---|---|---|---|
| Robotiq 사양식 | 0.647 | 20 N | 185 N |
| 실측 (rSP=128) | **0.245** (사양의 38%) | **101 N** | 162 N |

저 rFR 에서는 사양보다 훨씬 세게 잡고, 고 rFR 에서 사양에 근접한다. rSP=128 기준 실측/사양
비는 rFR 64 에서 1.73, 128 에서 1.27, 192 에서 1.03, 255 에서 0.87 이며 rFR ≈ 202 에서 교차한다.

**rFR 로는 약한 파지를 만들 수 없다.** 지령을 0 에 가깝게 낮춰도 100 N 안팎이 나온다.
연질·박벽 물체를 다루려면 rFR 이 아니라 rSP 를 낮추는 쪽이 실효적이다.

## gCU 로는 힘을 추정할 수 없다

파지 중(gOBJ=2) gCU 는 rFR 64/128/192/255 에서 3.4 / 3.6 / 4.0 / 4.3 (약 34~43 mA)로 단조
증가한다. 그러나 1 count = 10 mA 인데 전 범위가 3 count 에 불과하고 파지력과의 상관도
r = 0.478 로 약하다. gCU 포화 곡선으로 파지력을 대신하기에는 정보량이 부족하다.

물체 없이 목표 위치에 도달한 상태(gOBJ=3)에서는 유지 구간 gCU 가 전부 0 이었다.
gCU=0 은 파지 상태가 아니라 목표 도달 상태의 특성이므로 시뮬 판정 로직에서 두 상태를
구분해야 한다.

## 파지력은 rFR 보다 rSP 에 민감하다

- 전 범위 환산 기여: rSP 79.7 N > rFR 62.4 N
- rFR=64 고정, rSP 32 → 255 : 83.6 → 163.7 N (1.96배)
- rSP 고정, rFR 64 → 255 : 1.20~1.69배 (사양식은 3.01배)

**〔가설〕** 파지력이 100~200 N 인데 파지 중 gCU 는 34~43 mA 에 불과하다. 모터가 사양 최대에
해당하는 힘을 계속 내고 있다고 보기엔 너무 작다. 파지력의 상당 부분은 정지 순간에 갇힌 탄성
변형을 리드스크류의 자기잠금이 붙잡고 있는 것으로 볼 수 있다. 빠르게 닫을수록 감속 구간에서
더 깊이 파고들어 변형이 커지고 그대로 유지된다. rFR 은 감속 직전까지의 전류 상한만 정하므로
영향이 상대적으로 약하다.

확인하려면 ① 유지 시간을 늘려도 힘이 변하지 않는지, ② 정지 직후 rFR 만 올려도 힘이 오르지
않는지를 보면 된다. 본 시행은 파지 유지가 평균 0.42초뿐이라 ①을 확인할 수 없었다.
유지 시간을 10초로 둔 추가 시험이 필요하다.

## 시뮬 반영

- maxForce 를 rFR 만의 함수로 두면 안 된다. 위 2변수 식을 쓰거나, 최소한 파지 시나리오가
  실제로 쓰는 조합(rFR=128, rSP=128)의 **131 N** 을 기준으로 잡는다
- **사양식(20~185 N)을 그대로 쓰면 저 rFR 구간에서 힘을 5배까지 과소평가한다.** 실측식으로 대체할 것
- 실물–가상 비교 시 rFR 뿐 아니라 **rSP 까지 같은 값으로** 맞춰야 한다
