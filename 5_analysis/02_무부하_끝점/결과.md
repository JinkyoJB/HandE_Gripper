# 무부하 끝점

**목적** — 끝점 count 기준점과 재현성 확인
**수행** — 2026-07-14, 13개 런 × 5회 = 65회 (무부하, rSP=128)

## 결과

| 항목 | 값 | 비고 |
|---|---|---|
| gPO_open | **3** (σ = 0) | 65회 전부 동일 |
| gPO_closed | **249** (σ = 0) | 65회 전부 동일 |
| 가용 count 범위 | 246 count | 0~255 중 실제 사용 구간 |
| 레이저 실측 개방 위치 | 52.278 ± 0.006 mm | 측정 5회 정지 평균 |
| 레이저 실측 폐합 위치 | 0.038 ± 0.000 mm | 측정 5회 정지 평균 |
| **레이저 실측 스트로크** | **52.24 ± 0.006 mm** | 활성화 루틴 구간 제외 |
| 측정장비 로깅 | 119.1 s | 무부하 전개폐 반복 |

## 해석

끝점 재현성은 count 분해능 한계까지 완전하다. 65회 반복에서 표준편차가 0으로, 끝점은 기계적 스톱으로 고정된다.

주의할 점은 **사용 가능한 범위가 0~255가 아니라 3~249**라는 것이다. 시뮬 모델에서 count↔위치 매핑은 이 구간을 기준으로 잡아야 하며,
0이나 255를 끝점으로 두면 양단에서 각각 3 count(0.65 mm), 6 count(1.3 mm)의 오차가 생긴다.

레이저 실측 스트로크 52.24 mm 는 버니어 보정식이 예측하는 53.24 mm 와 1.00 mm(1.9%)
차이다. 버니어(손가락 끝면)와 레이저(손가락 측면)의 측정 기준면이 달라 생기는 것으로 보인다.

이 1.9% 때문에 **시뮬 모델은 버니어 회귀식을 그대로 쓰지 않는다.** 회귀식을 gPO 249 로
외삽하면 개구가 −0.404 mm 로 음수가 되기 때문이다. 기울기는 유지하고 여기 실측한 두 끝점
(52.278 / 0.038 mm)에 다시 고정한 `52.915 − 0.212358·gPO` 를 쓴다(README §3).

## 측정 시작부의 활성화 루틴

레이저 궤적 8.8 ~ 11.8 s 구간은 **측정 회차가 아니라 활성화(rACT) 루틴**이다. 5회 반복은 그 뒤 11.75 s부터 시작한다.

| 구간 [s] | 동작 | 최대 속도 |
|---|---|---|
| 8.83 ~ 9.19 | 52.4 → 0 mm 완전 폐합 | 161 mm/s |
| 9.57 ~ 9.72 | 2.9 → 0.1 mm 되튐 | 108 mm/s |
| 9.88 ~ 10.28 | 0 → **33.4 mm** 부분 개방 | 95 mm/s |
| 10.30 ~ 10.70 | 33.4 → 0 mm 재폐합 | 94 mm/s |
| 11.11 ~ 11.74 | 0 → 52.3 mm 완전 개방 | — |

활성화 루틴으로 판단한 근거는 다음과 같다.

1. 이후 14.23 ~ 42.11 s 사이에 **정확히 5회**의 개폐가 있고(폐합 5회), 이는 `EXP02_REPS = 5` 와 일치한다.
2. 초기 구간의 이동 속도(최대 161 mm/s)가 이후 측정 회차(전행정 0.62 s = 86 mm/s, rSP=128)보다 훨씬 빠르다.
   스크립트가 지정한 속도가 아니라 펌웨어 자체 루틴이라는 뜻이다.
3. 매뉴얼 4.3.1의 Warning — *rACT를 1로 설정하면 그리퍼가 활성화 동작을 시작한다* — 와
   `run.py`의 `routine_header()` 가 매 런 시작 시 재활성화를 수행하는 것이 일치한다.

측정 회차는 모두 전행정 0.62 s로 균일하다.

지표 산출에서 8~12.4 s 구간을 제외했다. 초기에 보고한 스트로크 52.41 mm는 이 구간의 순간 피크(t = 8.65 s)에서 잡힌 값이었다.
구간을 빼고 측정 5회의 정지 위치 평균으로 다시 구한 값이 52.24 ± 0.006 mm이며, 산포가 6 µm 수준으로 훨씬 안정적이다.
