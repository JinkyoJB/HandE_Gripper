## 1. 두 계통 시간 정합

두 PC의 시계가 독립적이라 실험마다 **동작 개시 시점(onset) 패턴 매칭**으로 오프셋을 구했다.

    측정장비 시각 = 제어 로그 시각 − offset

| 실험 | offset [s] | 겹침 [s] | 정합 후 상관 | 비고 |
|---|---|---|---|---|
| 힘 거동 | 88.88 | 174.4 | — | 유지구간 15개가 힘 평탄부와 일치 |
| 물체감지 타이밍 | 88.63 | 50.3 | r = 0.912 | 시편 파지로 개구 변화 제한 |
| 무부하 대조군 | 88.37 | 20.3 | — | 겹침 짧아 정량 비교 제외 |
| 미학습 조합 검증 | 88.42 | 58.1 | **r = 0.990** | 전 행정 왕복 — 교차검증 주 데이터 |

편차 0.2 s 이내로 일관된다. 제어 노트북 시계가 측정 PC보다 약 89초 빠르다.

> 위 오프셋은 별도 싱크 마커 없이 **사후 신호 정합**으로 구한 값이다.
> 두 계통을 함께 쓰는 분석에서는 이 점을 전제로 읽어야 한다.

병합 시계열은 `90_동기화/R05·R07·R09_동기화_시계열.csv` 에 있다 (측정장비 시간축 100 Hz, 컬럼: 시각 / gPO / gOBJ / gCU / 개구(gPO환산) / 개구(레이저) / 편차 / 파지력).

실물–가상 비교(시뮬 비교)의 결과는 저장소 최상위 문서를 참조한다.

## 3. 시뮬에 넘길 확정 파라미터

1. **위치** — 개구[mm] = 53.489 − 0.21644 × gPO, 유효 범위 gPO 3~249
2. **속도** — 평균 속도 = **21.6 + 0.499 × rSP** (레이저 실측, R²=0.9997). 사양식 20~150 mm/s 선형 매핑과 2 mm/s 이내 일치, 포화 없음
   제어 경로 오버헤드는 별도로 0.41 s (rSP=64는 미측정 — 추정값 사용 주의)
3. **힘** — **F [N] = 61.2 + 0.2446·rFR + 0.3126·rSP** (R²=0.977). rSP=128에서 107~162 N, 최대 197 N.
   로드셀 2채널의 **합**(KS B ISO 18646-3 5.3.3) 기준. 사양식(20~185 N)보다 기울기가 완만해 저 rFR에서 훨씬 세다
4. **판정** — 물체 접촉 시 gOBJ 전환 지연 239 ms 고정, 무부하 도달은 지연 없음

## 4. 합격 기준 대조

| 지표 | 기준값 | 실물 측 결과 | 판정 |
|---|---|---|---|
| 개구 오차 RMSE | 0.5 mm 이하 | 0.309 mm (실물 두 계통 간) | 기준선 확보 |
| gCU 곡선 상대 오차 | 15% 이하 | 파지 중 gCU 3.4~4.3 count — 분해능 부족 | 지표 대체 |
| gOBJ 판정 일치율 | 95% 이상 | 물체감지 타이밍 32/32, 무부하 대조군 8/8 | 기준선 확보 |
| 파지 성공/실패 | 100% (시편 A·B) | 파지 시나리오 3/3 (시편 A만) | 부분 확보 |

RMSE 0.309 mm는 **실물의 두 계통 간 일치도**다. 기준값은 원래 실물↔시뮬(실물–가상 비교) 비교용이므로,
"기준 통과"가 아니라 "실물 측 기준선이 기준값 안에 들어와 있다"로 읽어야 한다.

## 5. 후속 과제

- gCU 기반 힘 지표는 성립하지 않는다. 실물–가상 비교 비교 지표를 **정지 위치·전환 타이밍·파지력(로드셀)** 로 교체할 것.
- 파지력은 rFR=0 조건과 10초 유지 조건에서 추가 측정할 필요가 있다.
- 파지력은 rSP에도 크게 의존한다. 실물–가상 비교 비교 시 rFR·rSP를 모두 맞출 것.
- 파지 시나리오의 파지 정지 위치 gPO=103(개구 31.2 mm)이 시편 A(Ø45 mm)와 맞지 않는다. 실물–가상 비교 재현 전 시편·자세 조건 확인 필요.
- 싱크 마커를 실제로 수행해 기록할 것.
- 각 실험의 앞부분에는 활성화(rACT) 루틴이 들어간다. 지표 산출 시 이 구간을 제외할 것 (무부하 끝점 기준 약 3 s).
- 스크립트가 재는 이동시간에는 고정 오버헤드 0.41 s가 포함된다. 속도 지표는 레이저 실측을 기준으로 쓸 것.
