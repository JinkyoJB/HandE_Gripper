# Hand-E 가상화 실험 — 데이터 정리

Robotiq Hand-E 그리퍼의 Sim-to-Real 정합성 실험 11건 수행 결과를 정리한 폴더이다.
실험별 분석 결과는 `../5_analysis/` 를, 전체 개요는 저장소 최상위 `README.md` 를 참조한다.

정리 일자: 2026-07-27

---

## 폴더 구성

| 폴더 | 내용 | 수집 장비 |
|---|---|---|
| `0_스크립트_및_제어실행파일/` | 실험 실행 코드(Python)·현장 실행 배치파일(.bat)·설정 | — |
| `1_스마트그리퍼측정장비_데이터/` | 힘·변위·속도 계측 원시 데이터 | 스마트 그리퍼 기본 성능 시험 장비 (Clavis SV) |
| `2_로봇_그리퍼_제어_데이터/` | 그리퍼 레지스터 응답 로그 (gPO/gOBJ/gSTA/gFLT/gCU) | UR5e 연결 노트북 (63352 소켓 폴링) |

## 0_스크립트_및_제어실행파일

현장에서 `R0*_실행.bat`을 더블클릭하면 같은 폴더의 Python 스크립트를 호출하는 구조이므로,
**배치파일과 Python 스크립트는 반드시 동일 폴더에 함께 두어야 한다.**

| 파일 | 역할 |
|---|---|
| `config.py` | IP·포트·실험별 파라미터(레벨/반복수) 공통 설정 |
| `hande_client.py` | Robotiq URCap 소켓(63352) 클라이언트 — SET/GET, 활성화, 파지 대기 |
| `logger.py` | 별도 소켓으로 gPO/gOBJ/gSTA/gFLT(+gCU) 고속 폴링 → CSV 기록, 이벤트 마커 |
| `run.py` | 실험 실행기 (`python run.py r01` ~ `r10`, `summary`) |
| `r01_check_standalone.py` | 단독 점검 단독 실행용 점검 스크립트 |
| `r05_precheck.py` | 힘 거동 사전 검증 스크립트 |
| `r10_scenario.py` | 파지 시나리오 (UR 자동 이동 포함) |
| `r09_combos.csv` | 미학습 조합 검증 미학습 조합 10종 (사전 추첨 확정본, seed=20260714) |
| `R01~R10_실행.bat` | 현장 진행자용 실행 배치파일 (체크리스트 표시 후 스크립트 호출) |
| `README.md` | 코드 사용 설명서 (summary 워크플로 포함) |
| `requirements.txt` | 의존 패키지 (표준 라이브러리 외 파지 시나리오 자동 이동 시 `ur_rtde`) |
| `gripper.py`, `move_robot.py`, `pick_and_place.py`, `dashboard.py` | 초기 기능 검증용 스크립트 (본 실험 런에는 미사용) |
| `check_gripper_socket.py`, `ur_read_test.py` | 통신 점검용 보조 스크립트 |

> **주의** — `config.py`의 `OUTPUT_DIR = "logs"`는 스크립트 기준 상대경로이다.
> 재실행 시 새 CSV는 `0_스크립트_및_제어실행파일/logs/`에 생성되므로,
> 런 종료 후 `2_로봇_그리퍼_제어_데이터/`의 해당 런 폴더로 옮겨 정리한다.

## 1_스마트그리퍼측정장비_데이터

Clavis SV 소프트웨어 출력물이며, 실험마다 **2개 파일**이 한 쌍을 이룬다.

- `hand_*.csv` — 헤더 파일 (측정 채널 목록, Data interval 등 설정 정보)
- `hand_*_<YYYY-MM-DD HH-MM-SS>.csv` — 실제 측정 시계열 데이터

수집 채널: `Force 500N #1·#2`, `Laser Disp. #1·#2`, `Speed #1·#2` (샘플링 0.01 s = 100 Hz).
실험 설정 제약에 따라 **온도·LVDT 채널은 사용하지 않았다.**

| 폴더 | 대응 런 | 데이터 파일 | 행 수 |

- `handE_R**_<일시>.csv` — 원시 폴링 로그 (`t_perf, wall_time, POS, OBJ, STA, FLT, CUR`)

- `handE_R**_<일시>_result.csv` — 런 요약 결과 (실험계획표 기입용)

## 두 데이터의 시간 동기화

측정장비와 제어 로그는 **서로 다른 PC에서 수집**되어 시계가 독립적이다.
두 시계열을 겹쳐 분석할 때는 제어 로그 `_events.csv` 의 명령 시점과
측정장비 `Force` 채널의 급변 시점을 기준으로 정렬한다.

각 실험의 파일명 시각을 비교하면 측정장비 로깅이 제어 스크립트보다 **약 1~2분 먼저 시작**되었음을
확인할 수 있다(예: 힘 거동 — 측정장비 14:51:41 시작, 제어 로그 14:53 시작).
