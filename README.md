## 빠르게 보기

**1. 그리퍼를 직접 움직여 보려면** — `0_HandE_gripper.usd` 를 Isaac Sim 에서 연다.

1. 재생(Play) 버튼을 누른다. 액션 그래프는 재생 중에만 틱한다.
2. Stage 트리에서 `/Graph/HandE_Gripper/HandE_Control` 을 선택한다.
3. Property 패널의 **Inputs** 값을 바꾼다.

| 입력 | 레지스터 | 역할 |
| --- | --- | --- |
| `position` | rPR | 위치 — 0 완전 개방 ~ 255 완전 폐합 |
| `speed` | rSP | 개폐 속도 |
| `force` | rFR | 파지력 |
| `go_to` | rGTO | 1 이어야 이동한다 |
| `activate` | rACT | 1 로 두고 유지한다 |

결과는 `HandE_Model` 의 **Outputs** 에서 읽는다 — `gPO`(실제 위치)·`gOBJ`(물체 감지)·
`opening_mm`(개구 환산)·`grip_force_n`(파지력). 화면 예시는 `0_imgs/` 에 있다.

**2. 실물과 나란히 보려면** — 맨 위 영상, 또는 `6_video/R10_실물_가상_비교.mp4`.
R10 파지 시나리오(파지 → 상승 → 이송 → 회전 → 해제)를 실물과 시뮬에서 같은 지령으로 재생한 것이다.

## 모델의 핵심 — 실측으로 피팅한 상수

모든 값은 R02~R10 실측 결과이며, Isaac Sim 스크립트 노드가 이 상수를 그대로 쓴다.

```
위치   개구[mm] = 52.915 − 0.212358 × gPO        # 가용 gPO 3~249 → 개구 52.278~0.038 mm
에셋   개구[mm] = 46.292 + 2000 × q              # q_open +0.002993 / q_closed −0.023127
속도   개구속도[mm/s] = 21.6 + 0.499 × rSP       # R04 레이저 계측, R² = 0.9997
힘     F[N] = 61.2 + 0.2446 × rFR + 0.3126 × rSP # R05, R² = 0.977 (32회 시행)
전류   gCU = 3.052 + 0.00484 × rFR (파지 중)     # R07, r = 0.997
주기   레지스터 갱신 245 ms (4.08 Hz, sd 1.5 ms)
활성화 rACT 루틴 4.4 s
질량   base_link 0.990940 / left 0.038832 / right 0.038228 kg  (합 1.068 kg, 매뉴얼 5.1.2)
```

**245 ms 가 이 모델의 설계 중심이다.** gPO·gOBJ·gCU 는 245 ms 마다 함께 갱신되고,
gOBJ 전환의 87%가 gPO 변화와 같은 폴에 떨어진다. 즉 흔히 "물체 감지 디바운스"로 보고되는
239 ms 는 펌웨어 내부 지연이 아니라 **레지스터 한 주기**다. 모델은 별도 디바운스 상수 없이
`REG_PERIOD_S` 샘플링만으로 이를 재현한다.

## 실행 방법

### 실물 실험 코드 (`3_experiment_code/`)

UR5e 펜던트의 Robotiq URCap 소켓(63352)에 접속해 레지스터를 읽고 쓴다.
현장에서는 `R0*_실행.bat` 을 실행했고, 배치파일과 파이썬 스크립트는 같은 폴더에 있어야 한다.

```bash
pip install -r requirements.txt
python run.py r02        # 런 실행
python run.py summary    # 요약
```

로봇·PC IP 는 `config.py` 의 기본값(`192.168.1.10` / `192.168.1.50`)을 환경에 맞게 고친다.
상세 사용법은 `3_experiment_code/README.md`.

### 분석 재현 (`5_analysis/00_분석스크립트/`)

`4_raw_data/` 의 두 계통을 시간 정합해 `5_analysis/` 의 표·그래프를 다시 만든다.
```bash
cd 5_analysis/00_분석스크립트
python3 analyze.py    # 지표 산출 + matplotlib 그림
python3 refine.py     # 정지구간 기준 동기화 교차검증
python3 makesvg.py    # 경량 SVG 그래프
python3 export.py     # 결과 CSV·그래프 재생성
```
필요 패키지: numpy, matplotlib.

두 PC 의 시계가 독립적이라 런마다 동작 개시(onset) 패턴 매칭으로 오프셋을 구했다 —
값은 `5_analysis/90_동기화/시계_오프셋.csv`.

## 데이터 형식

`4_raw_data/` 는 계측 계통이 둘이고, 그래서 시계도 둘이다.

* **`1_스마트그리퍼측정장비_데이터/`** — 스마트 그리퍼 기본 성능 시험 장비(Clavis SV) 로 받은
  힘·변위·속도 계측값. 런별 폴더에 CSV.
* **`2_로봇_그리퍼_제어_데이터/`** — UR5e 연결 노트북이 63352 소켓을 고속 폴링해 남긴
  그리퍼 레지스터 로그 (gPO/gOBJ/gSTA/gFLT/gCU). 런별 폴더에 CSV.

두 계통을 정합한 병합 시계열은 `5_analysis/90_동기화/R0*_동기화_시계열.csv` 에 있다.
